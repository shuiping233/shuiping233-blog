# 什么是 WinUI 3

WinUI 3 是微软推出的新一代原生 Windows 桌面应用 UI 框架,它把 Windows App SDK 与现代 Fluent Design 语言结合,让开发者可以用 XAML 构建漂亮的 Windows 应用。

## 核心特点

- **原生性能**:直接基于 Windows 原生渲染管线,不依赖 WebView
- **Fluent Design**:内置 Mica、Acrylic 等现代背景材质与流畅的动效
- **统一开发体验**:与 UWP XAML 一脉相承,迁移成本低
- **桌面优先**:面向 Win32 桌面应用,支持完整的窗口管理

## 与旧框架的对比

| 框架 | 部署方式 | 更新渠道 | 适用场景 |
| --- | --- | --- | --- |
| WinUI 3 | 随应用分发 | Windows App SDK | 新桌面应用 |
| UWP XAML | 系统组件 | Windows 更新 | 商店应用 |
| WPF | .NET 运行时 | .NET 更新 | 传统企业应用 |

## 什么时候选择 WinUI 3

如果你正在开发一个新的 Windows 桌面应用,并且希望:

1. 拥有现代、统一的 Fluent 视觉风格
2. 完全掌控应用的发布与更新节奏
3. 获得接近原生的性能

那么 WinUI 3 是一个非常好的选择。
